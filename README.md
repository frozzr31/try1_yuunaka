# ⚡ Modern AI & Futuristic Portfolio

An interactive, responsive, dark-themed personal portfolio website featuring futuristic grid backgrounds, neon green glow accents, smooth scrolling animations, and a clean project showcase.

🌐 **Live Demo**: <https://frozzr31.github.io/try1_yuunaka/>

## 🌟 Key Features

* 🌌 **Dark Futuristic Aesthetics**: Built with customized CSS variables, radial glowing gradients, and grid overlays.

* ⚡ **Seamless Transitions**: Smooth scroll overlay effects and section fade-in animations driven by JavaScript Intersection Observers.

* 📱 **Fully Responsive**: Optimized for both mobile devices (with a custom hamburger menu) and desktop screens.

* 🔒 **Privacy-First Architecture**: Integrated public email contact option without exposing raw phone numbers.

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3, JavaScript (ES6+)

* **Design & Typography**: Plus Jakarta Sans, Custom UI/UX Grid Components

* **Hosting & Version Control**: Git, GitHub Pages

## 🚀 Getting Started

To run or customize this portfolio locally:

1. **Clone the repository**:

   ```
   git clone https://github.com/frozzr31/try1_yuunaka.git
   
   ```

2. **Navigate into the project directory**:

   ```
   cd try1_yuunaka
   
   ```

3. **Open in browser**:
   Simply open `index.html` in your favorite Web Browser (or use Live Server in VS Code).
